---
title: Evaluate the stored whole
description: Read and grade the exact aggregate version rather than a component trace.
navigation:
  icon: i-lucide-clipboard-check
---

A multi-part invoice can have valid individual parts but fail a cross-part rule: the totals step might use a different line count. Evaluate the published aggregate, not the last leaf response.

The ledger stores output JSON and feedback against a versioned `OutputRef`. The command's prompt and parameter snapshot and the provider's attempt snapshot are separate observations. Retain them through a host-owned capture path when an evaluation needs that input context. A trace can link work, but it is not a substitute for the stored value. See [Telemetry and evaluation capture](/guides/accounting-and-observability).

The following excerpt continues the [composition example](/guides/composition). It assumes `outcome` is the result of `root.ExecuteAsync`, and `provider`, `ledger` and the authorized `actor` come from the host.

```csharp [Evaluate excerpt] {6-7,18-19}
if (outcome is not CompositeOutcome<DocumentExtraction>.Published published)
{
    throw new InvalidOperationException("The whole was not published.");
}

var outputRef = published.Aggregate.Output;
if (ledger.ReadOutput(outputRef, actor) is not LedgerResult<OutputArtifact>.Accepted stored)
{
    throw new InvalidOperationException("The stored whole is unavailable.");
}

var descriptor = provider.GetRequiredService<CompositionRegistry>()
    .Find<DocumentExtraction>()
    ?? throw new InvalidOperationException("The whole contract is missing.");
var whole = stored.Value.Value.Deserialize(descriptor.Whole)
    ?? throw new InvalidOperationException("The stored whole could not be decoded.");

if (whole.LineItems.Count < 0 || whole.Totals.Amount < 0)
{
    throw new InvalidOperationException("The stored invoice failed evaluation.");
}

var grade = new GradeRequest(
    Guid.NewGuid(), outputRef, "", stored.Value.Value, 1.0,
    "The stored invoice has a nonnegative line count and total"
);
if (ledger.RecordGrade(grade, actor) is not LedgerResult<GradeReceipt>.Accepted)
{
    throw new InvalidOperationException("The grade was not recorded.");
}
```

The example checks two simple invariants against `whole`. Use the cross-part rules your application needs. The empty JSON pointer targets the root; a different pointer can target a part of that same stored output. The `ObservedValue` above is the value read from the ledger. Replaying the same grade event can return a replay receipt.

The aggregate's producer is a composition. Its component execution IDs remain useful lineage, but none is a substitute for the aggregate `OutputRef`. Reconstructing the whole from traces or grading every leaf would ask a different question.

::note
The default ledger is in memory. Use a host-provided `IHumanFeedbackLedger` when your application needs persistence, access control or retention beyond that default.
::
