A successful model response is not necessarily a complete accounting record. A provider may omit a count, a stream may end early, or a model's price may be unknown. Treat those values as **unknown**, not zero.

## Capture each attempt

`Zeeq.LlmCmd.Providers` normalizes observations into snapshots. A provider response adapter reads protocol accounting. An optional native response projector bridges an SDK response to the provider wire shape. An `IExtractionSink` consumes the normalized result. These roles are independent: a provider adapter does not need to know about Langfuse or another platform.

Place `ProviderExtractionChatClient` next to the provider client, inside retry, fallback and tool loops. That placement observes each actual model attempt. It delegates the response to its caller; adapter and sink failures do not change the provider result. The host still owns the surrounding MEAI pipeline and its client lifetime.

```text [Pipeline placement]
Application → retry / fallback / tool loop → attempt capture → provider client
```

Native streaming accounting and the OpenAI Responses extraction path have explicit limits. Check the adapter contract for the protocol and stream mode you use before assuming a count is available.

## Estimate observed usage

A pricing estimate combines a normalized `ResponseSnapshot` with a caller-asserted `PricingScope`: SKU, actual tier and geography, plus a target binding or date where required. The result can be complete, partial or unpriced. A complete estimate covers supported token partitions; it does not reconcile an invoice or establish the model behind a deployment name.

For example, the application can pass an already captured snapshot and its verified scope to `PricingEstimator.Estimate(snapshot, scope)`. Keep the rate provenance and assumptions with the estimate. Do not replace missing usage or missing price data with zero.

## Emit telemetry

`Zeeq.LlmCmd.OpenTelemetry` provides `AddLlmCmdInstrumentation()` for the host's tracer and meter providers. It subscribes to LlmCmd sources without selecting an exporter. The host chooses export, retention and access controls. Propagated references must still be resolved and authorized by the receiving host; correlation is not authority.

::note
The local package-only NativeAOT proof uses a synthetic MEAI client. It does not establish NativeAOT support for every vendor SDK or guarantee that a hosted collector has accepted a record.
::
