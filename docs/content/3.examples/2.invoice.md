Microsoft.Extensions.AI (MEAI) already offers typed `GetResponseAsync<T>` and JSON schema helpers. An invoice application may also need to retain which prompt definition, parameters and execution settings produced a result, then evaluate the stored output. `PromptCommand<TParameters, TResult>` adds those command, capture and outcome boundaries while using the host's MEAI client.

One manual integration might repeat prompt and JSON handling at the call site. MEAI's typed helpers are another option; this simplified sketch uses a host-supplied `SendPromptAsync` helper:

```csharp [Before: illustrative host code]
var prompt = $"Extract an invoice from {document}.";
var json = await SendPromptAsync(prompt, cancellationToken);
using var parsed = JsonDocument.Parse(json);
var total = parsed.RootElement.GetProperty("Total").GetDecimal();
```

The application must separately retain the template, input, schema and outcome if it wants to inspect them later. The command below makes those boundaries explicit.

This example follows `examples/Zeeq.LlmCmd.CommandExample`. Its `DemoClient` returns fixed JSON; it does not call a provider. Run it from the repository:

```sh [Terminal]
mise run demo:command
```

## Declare the contract

These are the actual DTOs and command declaration from the sample:

```csharp [ExtractInvoice.cs]
using Zeeq.LlmCmd;

namespace CommandDemo;

public sealed record InvoiceParameters(string Document, string Locale = "en");
public sealed record Invoice(decimal Total, string Currency, int Count = 3);

public sealed partial class ExtractInvoice : PromptCommand<InvoiceParameters, Invoice>
{
    const string Id = "invoice.extract";
    const string UserTemplate = "Extract an invoice from {Document} ({Locale}).";
}
```

The generator supplies command plumbing and STJ metadata for these plain records. The schema and reader use the same contract: `Total` and `Currency` are required; an omitted `Count` keeps its default of `3`. No `[JsonSerializable]` root is needed for this default path.

## Configure and execute

The sample registers two keyed MEAI clients, named profiles and a trusted actor, then calls `AddGeneratedCommands()`. This excerpt starts after the host has resolved `ExtractInvoice` from DI:

```csharp [Program.cs]
var invocation = extract
    .WithParameters(new InvoiceParameters("Invoice for USD 12.50", "en"))
    .WithProfile("extraction");

var outcome = await invocation.ExecuteAsync();
if (outcome is Outcome<Invoice>.Success success)
{
    Console.WriteLine($"{success.Value.Total} {success.Value.Currency}");
}
else if (outcome is Outcome<Invoice>.Failed failed)
{
    Console.WriteLine($"Extraction failed: {failed.Failure.Kind}");
}
```

`WithParameters` and `WithProfile` return immutable invocations. `ExecuteAsync` is the terminal call. A success contains the typed value, snapshot, execution context and delivery receipt. Check `success.Delivery` before assuming an output was stored. A failure retains its `ExecutionFailure` and context; a malformed response is not an `Invoice`.

The sample also sends `{"Total":12.5}` and checks for `ExecutionFailure.InvalidOutput`. That negative case matters: a JSON object is not automatically a valid result.

::note
The default ledger and composition store are in memory. Replace them for durable application requirements. The supplied actor must come from your trusted host policy; a run ID is not authorization.
::
