A document may need several extraction passes. The important result is the assembled invoice, not whichever leaf happened to run last. This example follows the runnable `examples/Zeeq.LlmCmd.CompositionExample`; its client is synthetic and offline.

```sh [Terminal]
mise run demo:composition
mise run demo:composition --quick
```

The whole is a plain record marked for composition. `Header`, `Parties`, `LineItems` and `Totals` are separate typed parts. The explicit JSON name demonstrates that a stored field name can differ from its CLR name.

```csharp [Commands.cs]
[CompositeOutput("invoice.composite", Revision = 1)]
public sealed partial record DocumentExtraction(
    [property: JsonPropertyName("header_data")] Header Header,
    Parties Parties,
    LineItems LineItems,
    Totals Totals
);
```

The host registers a trusted actor, a client and profile with `AddLlmCmd`, then calls `AddGeneratedCommands()`. It obtains `IRootCommands` and the typed commands from DI. This excerpt uses those resolved services and a run created by the ledger:

```csharp [Program.cs] {1-3,5-8,10-15}
var root = await roots.BeginAsync<DocumentExtraction>(
    new CompositionRequest(runId, "input-v1", "demo")
);

root.WithHeaderFrom(header.WithParameters(text))
    .WithPartiesFrom(parties, text);
root.WithLineItemsFrom(lines.WithParameters(text));

root.WithTotalsFrom(
    root.Steps.LineItems.Then(pinned =>
        totals.WithParameters(new TotalsParameters(text.Document, pinned.Value.Count))
    )
);

var outcome = await root.ExecuteAsync();
```

The `With...From` calls register work; they do not call the client. `Then` receives the exact stored line-item value and reference after that step attaches. The sample also uses ordinary `if/else` to choose a detailed or quick line-item command. A registered, compatible stored part can be attached with a generated `Reuse...` method; the runtime checks its reference and authority.

## Read and grade the stored whole

Handle `Published` before using the aggregate. The following excerpt keeps the root output reference, reads it from the ledger and grades that exact stored JSON. `actor`, `ledger` and `provider` are the same host services used for execution. The excerpt uses the `System.Text.Json`, `Microsoft.Extensions.DependencyInjection`, `CompositionDemo` and `Zeeq.LlmCmd` namespaces.

```csharp [Program.cs]
if (outcome is not CompositeOutcome<DocumentExtraction>.Published published)
{
    throw new InvalidOperationException("Composition did not publish.");
}

var outputRef = published.Aggregate.Output;
if (
    outputRef.Producer is not ProducerRef.Composition producer
    || producer.Id != published.DraftId
    || outputRef.ExecutionId is not null
)
{
    throw new InvalidOperationException("The aggregate has the wrong producer.");
}

if (ledger.ReadOutput(outputRef, actor) is not LedgerResult<OutputArtifact>.Accepted stored)
{
    throw new InvalidOperationException("The aggregate could not be read.");
}

var descriptor = provider.GetRequiredService<CompositionRegistry>()
    .Find<DocumentExtraction>()
    ?? throw new InvalidOperationException("Missing aggregate contract.");
var whole = stored.Value.Value.Deserialize(descriptor.Whole)
    ?? throw new InvalidOperationException("Invalid stored aggregate.");

// These expected values belong to the offline fixture, not every invoice.
if (
    whole.Header.Number != "INV-1"
    || whole.Parties.Seller != "Example Co"
    || whole.LineItems.Count != 2
    || whole.Totals.Amount != 12.50m
)
{
    throw new InvalidOperationException("The stored whole failed evaluation.");
}

var gradeRequest = new GradeRequest(
    Guid.NewGuid(), outputRef, "", stored.Value.Value, 1.0,
    "The stored invoice satisfies its cross-part checks"
);
var grade = ledger.RecordGrade(gradeRequest, actor);
var replay = ledger.RecordGrade(gradeRequest, actor);
if (
    grade is not LedgerResult<GradeReceipt>.Accepted accepted
    || accepted.Replayed
    || accepted.Value.Event.Target != outputRef
    || accepted.Value.Event.Pointer != ""
    || !JsonElement.DeepEquals(accepted.Value.Event.ObservedValue, stored.Value.Value)
    || replay is not LedgerResult<GradeReceipt>.Accepted replayed
    || !replayed.Replayed
    || replayed.Value.Event.Target != outputRef
    || replayed.Value.Event.EventId != gradeRequest.EventId
)
{
    throw new InvalidOperationException("Grade or replay did not preserve the stored aggregate.");
}
```

The guard checks the stored invoice number, seller, count and total against this fixture before assigning its score. A production evaluator needs its own expected values or cross-part rules. The grade and replay receipts must name the same aggregate output. The sample also executes the same root handle again and checks that no extra model call runs.

::note
The default store and ledger are in memory. Replay on a live handle and grade-event idempotency are not restart recovery, durable leases or exactly-once provider billing.
::
