An invoice total looks wrong. You want to see what was asked, which provider attempt ran, and what the application actually stored. Those are related pieces of evidence, but they don't all come from the same place.

In this example, the command uses a fake client and stores the invoice in an in-memory ledger. The host captures the provider attempt and retains the command inputs. Later, a reviewer selects a retained run for a dataset and grades its exact stored output against a known fixture. The console runs both stages locally.

This example extends the [quick start](/getting-started/quick-start). Keep its `ExtractInvoice.cs` and local NuGet feed. Add `Zeeq.AgentCmd.Providers` version `0.1.0-alpha.1` to the project, add the helper files below, and replace `Program.cs` with the execution listing. The last section contains the offline-only helpers.

## Set up attempt capture

This helper registers a keyed MEAI client with attempt capture at its inner boundary. The sink keeps attempt records in memory for this example. A real sink can forward them to a host-owned destination.

```csharp [CaptureSetup.cs]
using System.Collections.Concurrent;
using System.Text.Json;
using Microsoft.Extensions.AI;
using Microsoft.Extensions.DependencyInjection;
using Zeeq.AgentCmd.Providers;

namespace QuickStart;

public static class CaptureSetup
{
    public static void AddClient(
        IServiceCollection services,
        Func<IServiceProvider, IChatClient> createProvider,
        IAttemptSink sink
    )
    {
        services.AddAttemptSink(sink);
        services
            .AddKeyedChatClient("azure", createProvider)
            .UseAttemptCapture(Protocols.AzureOpenAIChatCompletions, "azure");
    }

    // Manual capture is useful when the host already has a completed response.
    public static ExtractionResult CaptureExisting(
        ChatResponse response,
        string attemptId,
        JsonElement? wire = null
    )
    {
        var protocol = Protocols.AzureOpenAIChatCompletions;
        var extractor = new ProviderExtractor(new ProviderAdapterRegistry(protocol.Adapters));
        return extractor.Extract(protocol.Identify("azure"), response, attemptId, wire);
    }
}

public sealed class AttemptSink : IAttemptSink
{
    private readonly ConcurrentQueue<AttemptRecord> attempts = new();

    public AttemptRecord[] Attempts => attempts.ToArray();

    public ValueTask OnAttemptAsync(
        AttemptRecord attempt,
        CancellationToken cancellationToken
    )
    {
        attempts.Enqueue(attempt);
        return ValueTask.CompletedTask;
    }
}
```

## Retain the inputs for later evaluation

The ledger stores the output and its feedback, but not the prompt or parameters. `RetainAsync` pairs the command's `ExecutionSnapshot` with the exact stored output reference and hands them to an `IEvaluationInputStore`. The store is your code, so you choose where the data goes and how long it stays. The offline helpers below define an in-memory one.

If the output was not stored, `RetainAsync` returns `RetainResult.NotStored` and saves nothing. A valid value alone is not an evaluation artifact.

## Execute and retain the evidence

The request path ends after it stores the output and retains the evidence needed for later selection. The console uses the same process to demonstrate both stages because its stores are in memory.

```csharp [TelemetryProgram.cs]
using System.Collections.Concurrent;
using System.Diagnostics;
using Microsoft.Extensions.AI;
using Microsoft.Extensions.DependencyInjection;
using QuickStart;
using Zeeq.AgentCmd;
using Zeeq.AgentCmd.Generated;

var activities = new ConcurrentQueue<string>();

// A listener must be present when the command starts to record its activities.
using var listener = new ActivityListener
{
    ShouldListenTo = source => source.Name == "Zeeq.AgentCmd",
    Sample = (ref ActivityCreationOptions<ActivityContext> _) =>
        ActivitySamplingResult.AllData,
    ActivityStopped = activity => activities.Enqueue(activity.OperationName),
};
ActivitySource.AddActivityListener(listener);

var actor = new Actor("demo", "reviewer");
var sink = new AttemptSink();
var client = new SyntheticClient();
var services = new ServiceCollection();

// The provider wrapper observes attempts without changing the command call site.
CaptureSetup.AddClient(services, _ => client, sink);
services
    .AddAgentCmd(options =>
        options
            .AddChatClient("azure")
            .AddProfile("extract", "azure", "synthetic-model")
            .UseActor(_ => actor)
    )
    .AddGeneratedCommands();

using var provider = services.BuildServiceProvider();
var command = provider.GetRequiredService<ExtractInvoice>();
var ledger = provider.GetRequiredService<IHumanFeedbackLedger>();
var outcome = await command
    .WithParameters(new InvoiceInput("Invoice for USD 12.50"))
    .ExecuteAsync();

if (
    outcome
    is not Outcome<Invoice>.Success { Delivery: OutputDelivery.Stored stored } success
)
{
    throw new InvalidOperationException("The invoice was not stored.");
}

var attempt = sink.Attempts.Single().Snapshot;
var outputRef = stored.Output.Reference;

// Keep prompt inputs linked to the version the ledger accepted.
var inputs = new InMemoryEvaluationInputs();
if (await success.RetainAsync(inputs) is not RetainResult.Retained)
{
    throw new InvalidOperationException("The output was not stored.");
}
var retained = inputs.Items.Single();
if (
    retained.Output != outputRef
    || retained.Snapshot.RawTemplate != "Extract the invoice from {Document}."
    || retained.Snapshot.Parameters.Single().Name != "Document"
)
{
    throw new InvalidOperationException("The evaluation input was not captured.");
}

// This second extraction illustrates the manual API. Do not publish it again
// as a new attempt unless the host deliberately handles duplicate observations.
var manual = CaptureSetup.CaptureExisting(client.LastResponse!, "manual-example");
if (
    attempt.Usage.Input != 7
    || manual.Snapshot.Usage.Input != 7
    || !activities.Contains("agentcmd.execute")
)
{
    throw new InvalidOperationException("Capture did not observe the expected work.");
}

// These inputs and outputs are synthetic. Apply a data policy to real records.
Console.WriteLine(
    $"Prompt: {success.Snapshot.PromptId}; input tokens: {attempt.Usage.Input}"
);
Console.WriteLine($"Template: {retained.Snapshot.RawTemplate}");
foreach (var parameter in retained.Snapshot.Parameters)
{
    Console.WriteLine($"{parameter.Name}: {parameter.Value}");
}

Console.WriteLine("Invoice execution finished. Evidence retained for later selection.");

// Simulate the reviewer returning later to select an invoice run.
var selected = inputs.Items.Single(input => input.Snapshot.PromptId == "invoice.extract");
var datasetCase = new InvoiceDatasetCase(selected.Output, ExpectedTotal: 12.50m);
if (InvoiceDatasetGrader.Grade(datasetCase, ledger, actor) != 1.0)
{
    throw new InvalidOperationException("The synthetic invoice did not pass evaluation.");
}
```

## Build the dataset and grade later

In this example, the reviewer searches the host’s retained input records by prompt ID and selects a run. The case keeps the exact output reference and an independently supplied expected total. The grader uses the reference to read the stored JSON under an authorized actor.

```csharp [InvoiceDatasetGrader.cs]
using Zeeq.AgentCmd;

namespace QuickStart;

sealed record InvoiceDatasetCase(OutputRef Output, decimal ExpectedTotal);

static class InvoiceDatasetGrader
{
    public static double Grade(
        InvoiceDatasetCase item,
        IHumanFeedbackLedger ledger,
        Actor actor
    )
    {
        if (ledger.ReadOutput(item.Output, actor) is not LedgerResult<OutputArtifact>.Accepted read)
        {
            throw new InvalidOperationException("The stored output could not be read.");
        }

        var observedTotal = read.Value.Value.GetProperty("Total");
        var score = observedTotal.GetDecimal() == item.ExpectedTotal ? 1.0 : 0.0;
        var grade = ledger.RecordGrade(
            new GradeRequest(Guid.NewGuid(), item.Output, "/Total", observedTotal, score, "Expected total"),
            actor
        );
        if (grade is not LedgerResult<GradeReceipt>.Accepted)
        {
            throw new InvalidOperationException("The grade was not recorded.");
        }

        Console.WriteLine($"Stored output: {read.Value.Value.GetRawText()}");
        Console.WriteLine("The exact stored total was read and graded.");
        return score;
    }
}
```

## Offline helpers

Add this file to run the example. The fake client returns a fixed invoice and usage counts; the input store keeps the captured record in memory. Neither contacts a service.

::code-collapse{label="Offline helpers"}

```csharp [TelemetryFakes.cs]
using Microsoft.Extensions.AI;
using QuickStart;
using Zeeq.AgentCmd;

// This store lasts only as long as the process. Replace it for durable records.
sealed class InMemoryEvaluationInputs : IEvaluationInputStore
{
    public List<EvaluationInput> Items { get; } = [];

    public ValueTask SaveAsync(
        EvaluationInput input,
        CancellationToken cancellationToken
    )
    {
        Items.Add(input);
        return ValueTask.CompletedTask;
    }
}

// A deterministic response makes this example safe to run without a provider.
sealed class SyntheticClient : IChatClient
{
    public ChatResponse? LastResponse { get; private set; }

    public Task<ChatResponse> GetResponseAsync(
        IEnumerable<ChatMessage> messages,
        ChatOptions? options = null,
        CancellationToken cancellationToken = default
    )
    {
        LastResponse = new ChatResponse(
            new ChatMessage(ChatRole.Assistant, """{"Total":12.50,"Currency":"USD"}""")
        )
        {
            ModelId = "synthetic-model",
            Usage = new()
            {
                InputTokenCount = 7,
                OutputTokenCount = 3,
                TotalTokenCount = 10,
            },
        };
        return Task.FromResult(LastResponse);
    }

    public IAsyncEnumerable<ChatResponseUpdate> GetStreamingResponseAsync(
        IEnumerable<ChatMessage> messages,
        ChatOptions? options = null,
        CancellationToken cancellationToken = default
    ) => throw new NotSupportedException();

    public object? GetService(Type serviceType, object? serviceKey = null) => null;

    public void Dispose() { }
}
```

::

The fake provides normalized MEAI usage but no native provider wire data, so extraction may be partial.

The input store and default ledger last for this process. To return after a restart, persist the searchable input records and the output ledger in durable storage. See [Telemetry and evaluation capture](/guides/accounting-and-observability) for the console’s regression dataset workflow and whole-output evaluation.
