The current packages are **local alpha artifacts**, version `0.1.0-alpha.1`. They are not yet published to a public feed. Use the SDK pinned by the repository's `global.json`: .NET 11 RC with C# 15 support.

From a checkout of this repository:

```bash [Terminal]
mise install
mise run pack
```

The packages are written to `artifacts/packages`. The core package is `Zeeq.LlmCmd`; it includes the runtime, generator and registration analyzer. `Zeeq.LlmCmd.Providers` and `Zeeq.LlmCmd.OpenTelemetry` are optional integrations.

For an app inside the checkout, create a local NuGet configuration next to the project. This example assumes the project is in `my-app/` at the repository root. The public source remains available for third-party dependencies.

```xml [my-app/NuGet.Config]
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <packageSources>
    <clear />
    <add key="local-llmcmd" value="../artifacts/packages" />
    <add key="nuget.org" value="https://api.nuget.org/v3/index.json" />
  </packageSources>
</configuration>
```

```xml [my-app/my-app.csproj]
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net11.0</TargetFramework>
    <LangVersion>15</LangVersion>
    <ManagePackageVersionsCentrally>false</ManagePackageVersionsCentrally>
    <Nullable>enable</Nullable>
    <ImplicitUsings>enable</ImplicitUsings>
  </PropertyGroup>
  <ItemGroup>
    <PackageReference Include="Zeeq.LlmCmd" Version="0.1.0-alpha.1" />
  </ItemGroup>
</Project>
```

The project disables central package version management because it is inside this checkout and declares its package version inline. A host that uses central package management can instead keep it enabled and put the version in its `Directory.Packages.props`.

Run `dotnet restore` from `my-app/`. For a project elsewhere, change the local feed path to the checkout's `artifacts/packages` directory. The source generator runs during normal compilation. You do not install a precompiler or add a serializer registration for ordinary DTOs.

::tip
The repository pins the SDK in `global.json`. Place an equivalent `global.json` above a standalone app if you want the same toolchain selection.
::
