A command declaration names a stable prompt and the types at its boundary. The generator supplies rendering, serializer metadata, schema, validators and registration.

```csharp [ExtractInvoice.cs]
using Zeeq.LlmCmd;

namespace QuickStart;

public sealed record InvoiceInput(string Document, string Locale = "en");
public sealed record Invoice(decimal Total, string Currency, int Count = 3);

public sealed partial class ExtractInvoice : PromptCommand<InvoiceInput, Invoice>
{
    const string Id = "invoice.extract";
    const string UserTemplate = "Extract an invoice from {Document} ({Locale}).";

    static string? ValidateInput(InvoiceInput input)
    {
        return string.IsNullOrWhiteSpace(input.Document) ? "Document is required" : null;
    }

    static string? ValidateResult(Invoice result)
    {
        return result.Total < 0 ? "Total cannot be negative" : null;
    }

    static partial void ConfigureDefaults(ChatSettingsPatch defaults)
    {
        defaults.Temperature = 0.2f;
    }
}
```

`Id` and `UserTemplate` are constants; `SystemTemplate` and `Profile` are optional constants. The placeholder name refers to a public input property. A bad or ignored placeholder fails generation. Keep the ID stable when changing code names; increment a prompt revision when the authored definition changes as appropriate for your application.

`Count` has a constructor default, so an absent value keeps `3`; it is not made required merely because it exists. Required members and nullability are represented in the generated contract. Nested validation also checks collection elements where applicable.

The validation hooks return `null` for success or a reason for failure. A thrown hook is a `HookFailure`, not a successful result. `ConfigureDefaults` supplies command-level defaults. Profile settings and explicit invocation settings can override defaults; see [Profiles and clients](/guides/profiles-and-clients).

::note
A configured invocation is a value you can branch from. Calling `WithProfile`, `WithTemperature` or `Configure` returns another invocation; work begins at `ExecuteAsync`.
::

The example uses plain DTOs. For attributes, unsupported shapes and explicit serializer contexts, see [Serialization and NativeAOT](/guides/serialization-and-nativeaot).
