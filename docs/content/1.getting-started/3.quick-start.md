Let's start with a small invoice extractor. Give it a sentence such as “Invoice for USD 12.50,” and it returns an `Invoice` with a total and currency.

We'll use a fake chat client that returns a known answer, so you can follow the whole path without an API key, a paid request, or a running service. First create the project and local package source described in [Installation](/getting-started/installation).

## 1. Declare the contract

Add this file to the application project. The input and output are ordinary records. The command is the reusable recipe that connects them to a prompt.

```csharp [ExtractInvoice.cs] {9,11,14}
using Zeeq.LlmCmd;

namespace QuickStart;

public sealed record InvoiceInput(string Document);

public sealed record Invoice(decimal Total, string Currency);

public sealed partial class ExtractInvoice : PromptCommand<InvoiceInput, Invoice>
{
    const string Id = "invoice.extract"; // Keep this stable across class renames.

    // Document comes from InvoiceInput, not string interpolation at the call site.
    const string UserTemplate = "Extract the invoice from {Document}.";
}
```

The `{Document}` placeholder refers to the input record's property. The generator uses the two record types to create the schema and serializer metadata during compilation; there is no `JsonSerializable` registration to maintain for this example.

## 2. Build the host and execute

Replace `Program.cs` with the following. The client returns a fixed JSON response, so the example needs no credentials or provider account.

```csharp [Program.cs]
using Microsoft.Extensions.AI;
using Microsoft.Extensions.DependencyInjection;
using QuickStart;
using Zeeq.LlmCmd;
using Zeeq.LlmCmd.Generated;

// The actor represents the trusted host identity for the output ledger.
var actor = new Actor("demo", "developer");

// Register the client and profile once. The generated catalog adds the command.
var services = new ServiceCollection()
    .AddLlmCmd(options =>
        options
            .UseChatClient(_ => new FakeClient())
            .AddProfile("extract", "synthetic-model")
            .UseActor(_ => actor)
    )
    .AddGeneratedCommands();

using var provider = services.BuildServiceProvider();
var command = provider.GetRequiredService<ExtractInvoice>();

// WithParameters prepares this invocation; ExecuteAsync sends the request.
var result = await command
    .WithParameters(new InvoiceInput("Invoice for USD 12.50"))
    .ExecuteAsync();

// A malformed response or provider failure is not an Invoice.
switch (result)
{
    case Outcome<Invoice>.Success success:
        Console.WriteLine($"{success.Value.Total} {success.Value.Currency}");
        break;
    case Outcome<Invoice>.Failed failed:
        Console.WriteLine($"Failed: {failed.Failure.Kind}");
        break;
}

// This client stands in for a provider, so the example is safe to run offline.
sealed class FakeClient : IChatClient
{
    public Task<ChatResponse> GetResponseAsync(
        IEnumerable<ChatMessage> messages,
        ChatOptions? options = null,
        CancellationToken cancellationToken = default
    )
    {
        return Task.FromResult(
            new ChatResponse(
                new ChatMessage(
                    ChatRole.Assistant,
                    """{"Total":12.50,"Currency":"USD"}"""
                )
            )
            {
                ModelId = "synthetic-model",
            }
        );
    }

    public IAsyncEnumerable<ChatResponseUpdate> GetStreamingResponseAsync(
        IEnumerable<ChatMessage> messages,
        ChatOptions? options = null,
        CancellationToken cancellationToken = default
    ) => throw new NotSupportedException();

    public object? GetService(Type serviceType, object? serviceKey = null) => null;

    public void Dispose() { }
}
```

```bash [Terminal]
dotnet run
```

You should see `12.50 USD` with an en-US number format. Try changing the input text: the fake still returns the same answer because it doesn't actually read the invoice. Swap it for your own `IChatClient` when you're ready to make a real request.

`UseChatClient` supplies a runtime-owned client. `UseActor` supplies trusted host authority. With only one profile, `extract` is the default.

## What happened?

1. The compiler generated a command contract and a catalog registration from the declaration.
2. `WithParameters` created an immutable invocation. It did not call the client.
3. `ExecuteAsync` rendered the prompt, sent it through the MEAI client, validated the JSON and returned a closed outcome.

A successful value and its output-delivery receipt are separate. In [Outcomes and context](/guides/outcomes-and-context), inspect `Snapshot.RawTemplate`, captured parameters, and the exact stored output reference before treating a result as a stored artifact. The repository's `examples/Zeeq.LlmCmd.CommandExample` also checks schema, profile switching and invalid output.
