This example sends no network request. It declares one command, registers a fake MEAI client and executes the generated command. First create the project and local package source described in [Installation](/getting-started/installation).

## 1. Declare the contract

Add this file to the application project. The stable ID identifies the authored prompt even if the C# class is renamed. The template uses the CLR parameter name `Document`.

```csharp [ExtractInvoice.cs] {7-11}
using Zeeq.LlmCmd;

namespace QuickStart;

public sealed record InvoiceInput(string Document);
public sealed record Invoice(decimal Total, string Currency);

public sealed partial class ExtractInvoice : PromptCommand<InvoiceInput, Invoice>
{
    const string Id = "invoice.extract";
    const string UserTemplate = "Extract the invoice from {Document}.";
}
```

There is no `JsonSerializable` registration here. The generator emits the serializer metadata and schema during compilation.

## 2. Build the host and execute

Replace `Program.cs` with the following. The client returns a fixed JSON response, so the example needs no credentials or provider account.

```csharp [Program.cs]
using Microsoft.Extensions.AI;
using Microsoft.Extensions.DependencyInjection;
using QuickStart;
using Zeeq.LlmCmd;
using Zeeq.LlmCmd.Generated;

var actor = new Actor("demo", "developer");
var services = new ServiceCollection()
    .AddLlmCmd(options =>
        options
            .UseChatClient(_ => new FakeClient())
            .AddProfile("extract", "synthetic-model")
            .UseActor(_ => actor)
    )
    .AddGeneratedCommands();

using var provider = services.BuildServiceProvider();
var command = provider.GetRequiredService<ExtractInvoice>();
var result = await command
    .WithParameters(new InvoiceInput("Invoice for USD 12.50"))
    .ExecuteAsync();

switch (result)
{
    case Outcome<Invoice>.Success success:
        Console.WriteLine($"{success.Value.Total} {success.Value.Currency}");
        break;
    case Outcome<Invoice>.Failed failed:
        Console.WriteLine($"Failed: {failed.Failure.Kind}");
        break;
}

sealed class FakeClient : IChatClient
{
    public Task<ChatResponse> GetResponseAsync(
        IEnumerable<ChatMessage> messages,
        ChatOptions? options = null,
        CancellationToken cancellationToken = default
    )
    {
        return Task.FromResult(
            new ChatResponse(
                new ChatMessage(ChatRole.Assistant, """{"Total":12.50,"Currency":"USD"}""")
            ) { ModelId = "synthetic-model" }
        );
    }

    public IAsyncEnumerable<ChatResponseUpdate> GetStreamingResponseAsync(
        IEnumerable<ChatMessage> messages,
        ChatOptions? options = null,
        CancellationToken cancellationToken = default
    ) => throw new NotSupportedException();

    public object? GetService(Type serviceType, object? serviceKey = null) => null;

    public void Dispose() { }
}
```

```bash [Terminal]
dotnet run
```

The output shows the total and currency, for example `12.50 USD` with an en-US number format. `UseChatClient` supplies a runtime-owned client. `UseActor` supplies trusted host authority. With only one profile, `extract` is the default.

## What happened?

1. The compiler generated a command contract and a catalog registration from the declaration.
2. `WithParameters` created an immutable invocation. It did not call the client.
3. `ExecuteAsync` rendered the prompt, sent it through the MEAI client, validated the JSON and returned a closed outcome.

A successful value and its output-delivery receipt are separate. In [Outcomes and context](/guides/outcomes-and-context), inspect `Snapshot.RawTemplate`, captured parameters, and the exact stored output reference before treating a result as a stored artifact. The repository's `examples/Zeeq.LlmCmd.CommandExample` also checks schema, profile switching and invalid output.
